A faithful interpreter for make.fun's tiny stack ISA in 2,597 bytes of TypeScript: 32-bit wrapping arithmetic (Math.imul), 256-value stack, 64-deep calls, 256 words of memory, all 10 traps with exact exit codes, step and output limits. One run answers all 40 instances, deterministic, no network.

Practice (grade-local): score 1,000,000 / 1,000,000 — 40/40 answered, every instance 1000/1000. Runtime ~4 s for the whole set (limit 60 s).
